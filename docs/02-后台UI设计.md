# 后台页面 UI 设计 —— 大连理工大学实训基地优秀项目展示系统

> 版本 V1.0 ｜ 2026-09-01 ｜ 对应评审：9 月 11 日原型评审
> 技术栈：Vue 3 + Element Plus（组件库）+ Pinia + Vue Router

---

## 1. 设计定位与原则

后台与前台是**两种完全不同的体验**：

| | 前台（Project Showcase） | 后台（Content Management） |
| --- | --- | --- |
| 目标 | 沉浸在内容里 | 快速编辑内容 |
| 气质 | 作品感、沉浸、留白 | 高效、清晰、少干扰 |
| 密度 | 卡片、大图 | 表格、表单、紧凑 |

**设计原则**：
1. **弱化存在感**：后台只是"内容的管理工具"，一切围绕"把内容又快又准地改好"。
2. **信息密度高但有序**：列表用表格而非大卡片（一次看更多）。
3. **核心编辑器优先**：项目编辑页是整个后台的重心（内容编排器），其他页面保持简单。
4. **两栏布局**：左侧固定导航 + 右侧内容区，顶栏放全局操作（用户、退出）。
5. **状态可视化**：上架/下架、推荐、内容完整性在列表页一眼可见。

- 搜索关键字命中 `名称 / 一句话介绍 / 技术栈标签`。
- 删除二次确认（el-popconfirm）："删除后项目将不再展示，确定？"

**目标**：一处完成项目全部内容管理。页面分两大部分：**基础信息区** + **内容编排区**。

**页面结构**：

```
│
════════════ Tab 1 基础信息 ═════════════════════════════════════
两列布局（左侧表单，右侧辅助/预览）：
┌─ 表单（左 2/3）───────────────────┐  ┌─ 封面预览（右 1/3）──────────┐
│ 项目名称 *  [MyGoVoice          ] │  │  [封面大图预览区]              │
│ 一句话介绍 * [A lightweight…    ] │  │  [上传封面]  [替换]           │
│ 分类 *       [开发类 ▾]           │  │  · 建议尺寸 16:9，≤5MB       │
│ 技术栈标签   [Go] [AST] [VS Code] ＋ │  │                              │

════════════ Tab 2 内容编排 ★（本项目核心）═══════════════════════
左侧：内容块列表（可视化排序），右侧：块类型工具面板

┌─ 内容块画布（左 2/3）────────────────────────────┬─ 插入面板（右 1/3）───┐
│ [添加小节] [添加段落] [添加图片]   → 拖拽排序       │ │ 块类型（点击插入）：   │
│ ┌────────────────────────────────────────┐      │ │  ┌──────────────┐  │

│ │ 段落：MyGoVoice 是一个轻量级 Go 代码     │      │ │ │ 图片（可带说明） │  │
│ │ 结构语音播报工具…                        │      │ │ └──────────────┘  │
│ ├────────────────────────────────────────┤      │ │ · 上移/下移按钮    │
│ │ 图片：[截图预览]  图片说明：核心界面        │  ✎ 🗑 │ │ · 拖拽手柄        │
│ ├────────────────────────────────────────┤      │ │ · 删除           │
│ │ 小节：功能特性 …                        │  ✎ 🗑 │ └──────────────────┘
│ │ …                                      │      │
│ └────────────────────────────────────────┘      │
│ [＋ 在底部添加内容块]                            │
└──────────────────────────────────────────────┴────────────────────┘

════════════ Tab 3 成员与标签 ════════════════════════════════════
┌─ 项目成员 ──────────────────────────┐  ┌─ 项目标签 ─────────────────┐
│ 姓名   [张三] 角色/职责 [后端开发]     │  │ [Go] [AST] [VS Code]  [＋]  │
│ [+ 添加成员]                          │  │ 从已有标签中选择/新建        │
│ 列表：张三 · 后端开发      🗑           │  │                           │
│       李四 · 前端开发      🗑           │  └──────────────────────────┘
└──────────────────────────────────────┘
```

**内容编排器核心交互**：
1. **插入**：点击右侧块类型 → 在光标/选中位置插入内容块；或点击块间"＋"插入。
2. **编辑**：块就地编辑（段落=textarea 自动增高；小节=单行输入；图片=上传/选图 + 说明文字）。
3. **排序**：拖拽手柄 + 每块"上移/下移"按钮（兼容键盘操作）。
4. **删除**：hover 显示 🗑，二次确认。
5. **保存策略**：整组内容块随项目一起"保存并发布"，后端事务内全量替换（保证顺序一致性）。
6. **草稿 vs 发布**：内容块修改后状态变"未保存"（★ 角标），保存后清除。

## 4. 关键组件与全局约定

| 组件/约定 | 设计 |
| --- | --- |
| 状态标签 | 上架=绿点`●`、下架=灰点`○`；推荐=星标`★` |
| 空状态 | 每个列表提供空态插画 + 引导按钮（如"去创建第一个项目"） |
| 加载态 | 表格骨架屏、按钮 loading 防重复提交 |
| 错误反馈 | 全局 toast；表单校验内联错误 |
| 删除确认 | 统一 popconfirm，红色危险按钮 |
| 图片上传 | 统一上传组件（拖拽/点击、压缩预览、进度、失败重试），限 jpg/png/webp/gif ≤5MB |
| 权限拦截 | 路由守卫：未登录跳 `/login`；Token 过期自动登出 |
| 深色模式 | 一期跟随系统（Element Plus 暗色主题），成本低可保留 |
| 响应式 | 后台以桌面为主（≥1280 优化），平板可降级为单列 |

## 5. 页面流转（关键路径）

```
登录 ──▶ 仪表盘 ──▶ 项目列表 ──▶ 新建/编辑项目
                              └──▶ 内容编排（Tab2）──▶ 保存并发布
   ↑____________________________│

前台浏览路径（供后台管理员预览参照）：
首页 ─▶ 项目卡片 ─▶ 项目详情 ─▶ 返回继续浏览
```

## 6. 原型工具建议

- 评审用 **高保真原型**（9/11 原型评审）：建议用 **Axure**（动态面板演示内容块拖拽）或 **Figma**（组件复用快、可直接导出组件图）。
- 本项目为 Vue 3 + Element Plus，原型用 Element Plus 组件风格，可直接映射到实现组件，减少开发转化成本。
