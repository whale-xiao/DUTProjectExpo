## 1. 概述

本文档描述系统内数据在各模块间的流转，说明"数据从哪来、到哪去、如何被加工"。数据来源主要有两类：**管理员在后台录入维护**，**访客在前台消费浏览**。

## 2. 顶层数据流（DFD 0 层）

```
          ┌──────────────┐         ┌──────────────┐
          │   管理员      │         │    访客       │
          └──────┬───────┘         └──────┬───────┘
                 │ 录入/维护             │ 浏览/搜索
                 ▼                        ▼
        ┌────────────────────────────────────────┐
        │        项目展示系统（前后端 + API）        │
        └──────────────────┬─────────────────────┘
                           │
                           ▼
                    ┌──────────────┐
                    │    MySQL      │
                    │ 项目/正文/标签/ │
                    │ 用户/图片      │
                    └──────────────┘
```

## 3. 核心流程数据流

### 3.1 浏览首页（推荐信息流）

```
访客 ──打开首页──▶ 前端 Home.vue
                      │ GET /api/projects?recommended=true
                      ▼
                  后端 service ──▶ repository ──▶ MySQL(projects)
                      │ 返回推荐项目列表
                      ▼
                  前端渲染项目卡片网格
```

**数据项**：项目封面、标题、一句话简介、技术标签、推荐标识。

### 3.2 搜索（即时联想 + 直达详情）

```
访客 ──输入关键词──▶ 前端搜索框（防抖）
                        │ GET /api/projects?q=keyword
                        ▼
                    后端：keyword → 匹配
                        Project.Name / Description / Content / TechStack
                        ▼
                    返回候选项目列表（联想下拉）
                        │ 点击某个项目
                        ▼
                    GET /api/projects/:id ──▶ 项目详情页
```

> 设计要点：搜索直接返回候选项目（名称/简介/标签），点击即进入详情，不经过独立搜索结果页。30 个项目规模下无需独立搜索引擎，SQL 模糊匹配即可满足。

### 3.3 查看项目详情（作品文章）

```
访客 ──点击卡片──▶ GET /api/projects/:id
                        ▼
                  后端：查 projects 基础信息
                        + 查 project_sections（按 sort 排序）
                        + 查 tags / 成员
                        ▼
                  组装为"作品文章"数据结构返回
                        ▼
                  前端按区块类型（标题/文本/图片）顺序渲染
```

### 3.4 管理员登录

```
管理员 ──账号密码──▶ POST /api/auth/login
                        │ 校验用户名密码
                        ▼
                     后端签发 JWT
                        │ 返回 token
                        ▼
                   前端存储 token，后续请求携带
                        │ Authorization: Bearer <token>
                        ▼
                   后端 JWT 中间件校验 ──▶ 放行受保护接口
```

### 3.5 项目新增/编辑（含图片上传）

```
管理员 ──填写表单──▶ 前端 ProjectEditor
                        │ 上传封面/配图 → POST /api/images
                        │    → 后端校验 → 存入 MySQL(images, BLOB)
                        │    → 返回图片 id
                        ▼
                   提交项目：POST/PUT /api/projects
                        │ 基础信息 → projects 表
                        │ 正文区块 → project_sections 表
                        ▼
                   后端返回项目 id ──▶ 前端跳转列表/详情
```

## 4. 项目状态流转

```
  [草稿] ──发布──▶ [已发布] ──下架──▶ [已下架]
     ▲                │
     └────编辑────────┘
```

| 状态 | 说明 | 前台可见 |
| --- | --- | --- |
| 草稿 | 新建未发布 | 否 |
| 已发布 | 正常展示 | 是 |
| 已下架 | 临时移除 | 否 |

---

## 5. 数据字典摘要

| 数据对象 | 主要字段 | 流向 |
| --- | --- | --- |
| 项目（projects） | title, summary, cover_id, tech_stack, members, recommended, status | 后台录入 → 前台展示 |
| 正文区块（project_sections） | project_id, sort, type, content, image_id | 后台录入 → 前台详情 |
| 标签（tags / project_tags） | name | 后台维护 → 前台筛选 |
| 图片（images） | data(BLOB), mime, size | 后台上传 → 前台读取 |
| 用户（users） | username, password_hash | 仅后台认证 |

> 详细表结构见《04-数据库设计.md》。
